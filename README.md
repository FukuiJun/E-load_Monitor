# SDL放電ロガー

Siglent 電子負荷 **SDL1020X-E** を LAN（TCP ソケット）で操作して、リチウムイオン電池の CC 放電試験を記録する Windows 用アプリです。

- 電圧・電流・電力を一定周期で取得してグラフにリアルタイム表示
- 放電容量（mAh）・電力量（Wh）を積算
- 終止電圧に達したら負荷を OFF にして自動で停止・保存（CSV と PNG）
- 試験条件（メーカー・満充電電圧・型番・備考）をファイル名と CSV に記録

仕様は [SPEC.md](SPEC.md) を参照してください。

---

## 導入

`SDL放電ロガー.exe` を好きなフォルダ（例：`C:\Tools\SDL放電ロガー\`）に置いてダブルクリックで起動します。
Python や NI-VISA などのドライバのインストールは不要です。

- 設定ファイル `sdl_logger_settings.json` とログ `sdl_logger.log` は **exe と同じフォルダ** に作られます。
  書き込みできるフォルダ（`C:\Program Files` 以外）に置いてください。
- exe は GitHub の **Actions** → 最新の「Build SDL放電ロガー.exe」→ **Artifacts** の `SDL-discharge-logger` からダウンロードできます（zip の中に exe と README）。

## ネットワーク設定（PC と SDL を LAN ケーブルで直結）

| 機器 | IP アドレス | サブネットマスク | ゲートウェイ |
|---|---|---|---|
| PC | 192.168.10.1 | 255.255.255.0 | （空欄） |
| SDL1020X-E | 192.168.10.2 | 255.255.255.0 | （空欄） |

**PC 側（Windows 11）**
1. 設定 →「ネットワークとインターネット」→「イーサネット」を開く
2. 「IP 割り当て」の［編集］→「手動」→ IPv4 をオン
3. IP アドレス `192.168.10.1`、サブネットマスク `255.255.255.0` を入れて保存（ゲートウェイ・DNS は空欄）

**SDL 側**
1. 本体の Utility から LAN（IO 設定）の画面を開く（メニュー名はファームウェアの版で多少異なります）
2. DHCP を OFF にし、IP `192.168.10.2`、サブネットマスク `255.255.255.0` を設定

ポートは SCPI の 5025 番（固定）です。つながらないときは、LAN ケーブル・IP の設定のほか、
Windows のファイアウォール／セキュリティソフトが通信を止めていないかも確認してください。

## 使い方

1. PC と SDL を LAN ケーブルで直結し、`SDL放電ロガー.exe` を起動する
2. ［接続］を押す（IP・ポートは前回値）。状態欄に `接続中  Siglent Technologies,SDL1020X-E,…` と出て、電圧が 1 秒ごとに表示されます
3. 必要ならメーカー・満充電電圧を選び（不明なら「未選択」のまま）、型番・備考を入力する（いずれも任意）
4. 放電電流・終止電圧・取得周期・保存先を確認して［放電開始］
5. グラフを見ながら待つ（備考は放電中も編集できます。保存した時点の内容が CSV に入ります）
6. 終止電圧に到達すると自動で負荷 OFF・保存され、ダイアログでお知らせします。
   途中でやめるときは［停止・保存］または［停止・破棄］（破棄は確認あり。ファイルは残りません）

| 画面の項目 | 内容 |
|---|---|
| メーカー | 未選択 / Panasonic / マクセル。起動時は未選択（前回値は引き継ぎません） |
| 満充電電圧 | 未選択 / 4.1V / 4.2V。起動時は未選択（前回値は引き継ぎません） |
| 型番 | 任意、最大 40 文字。起動時は空欄 |
| 放電電流[A] | 0.001〜5.000。5A 以下なので常に 5A レンジを使います |
| 終止電圧[V] | 2.000〜4.200。この電圧以下が **連続 3 回** 続いたら停止 |
| 取得周期[s] | 0.2〜60（既定 1.0） |
| 保存先 | ［参照］で選択。既定はデスクトップ |
| 備考 | 複数行・カンマ可。放電中も編集可 |
| ［グラフ保存］ | 表示中のグラフをいつでも PNG 保存（`<ベース名>_<時刻>.png`、未開始なら `graph_<日時>.png`） |

放電中はメーカー・満充電電圧・型番・放電電流・終止電圧・取得周期・保存先・接続は変更できません。
放電中にウィンドウを閉じると「保存して終了 / 破棄して終了 / キャンセル」を選べます。

### 出力されるファイル

ベース名は `<放電開始日時 YYYYMMDD_HHMMSS>[_<満充電電圧>][_<メーカー略称>]` です（未選択の部分は `_` ごと省きます）。

| 満充電電圧 | メーカー | ベース名 |
|---|---|---|
| 4.1V | Panasonic | `20261001_143005_4.1V_pana` |
| 4.2V | マクセル | `20261001_143005_4.2V_maxell` |
| 未選択 | Panasonic | `20261001_143005_pana` |
| 4.1V | 未選択 | `20261001_143005_4.1V` |
| 未選択 | 未選択 | `20261001_143005` |

同名のファイルがあるときは末尾に `_2`, `_3` … が付きます。

| ファイル | 内容 |
|---|---|
| `<ベース名>.csv` | 試験情報ブロック＋測定行（UTF-8 BOM 付き・CRLF。Excel でそのまま開けます） |
| `<ベース名>.png` | 終了時のグラフ（1600×1000 px） |
| `<ベース名>.partial.csv` | 放電中の一時ファイル（1 行ごとに書き込み）。正常に保存されると消えます |

CSV の例:

```
試験情報
開始日時,2026/10/01 14:30:05
終了日時,2026/10/01 17:12:40
終了理由,終止電圧到達
メーカー,Panasonic
満充電電圧[V],4.1
型番,NCR18650B
放電電流[A],1.000
終止電圧[V],3.000
放電容量[mAh],2702.5
電力量[Wh],9.874
取得周期[s],1.0
機器,"Siglent Technologies,SDL1020X-E,..."
備考,"25℃恒温槽内。2回目"

日時,経過時間[s],電圧[V],電流[A],電力[W],放電容量[mAh],電力量[Wh]
2026/10/01 14:30:05.120,0.000,4.18512,1.0002,4.1859,0.000,0.0000
2026/10/01 14:30:06.121,1.001,4.15020,1.0001,4.1506,0.278,0.0012
```

- 未選択・未入力の項目は値が空欄になります（行は残ります）
- 「機器」は IDN 文字列にカンマが入るため、ダブルクォートで囲んで 1 つのセルにしています
- 終了理由は「終止電圧到達」「手動停止」「通信断」「保存先書き込みエラー」「異常終了」のいずれか

### 異常時の動作

| 状況 | 動作 |
|---|---|
| 接続時に応答なし | 「接続できません。IP アドレスと LAN ケーブルを確認してください」 |
| 開始時の電圧が終止電圧以下 | 開始しません |
| 保存先に書けない・空き容量不足 | 開始しません |
| 放電中に応答なし・切断 | 1 秒間隔で最大 10 回再接続。復帰したら記録を続けます（欠損区間はそのまま）。復帰しなければ負荷 OFF を試み、「通信断」で保存 |
| 再接続できたが負荷が OFF になっていた（SDL の再起動など） | 「通信断」で保存して停止 |
| 数値でない応答 | その周期は記録しません。10 回続いたら「通信断」で保存して停止 |
| 放電中に保存先に書けなくなった | 負荷 OFF・停止してエラー表示 |
| 最終 CSV が作れない（同名ファイルを Excel で開いている等） | 一時ファイルを残し「保存できませんでした。一時ファイル: <パス>」 |
| 負荷 OFF を確認できなかった | **「SDL 本体で負荷を OFF にしてください」と表示**。本体を確認してください |
| 起動時に保存先に `*.partial.csv` がある | 「前回の記録が途中で終了しています: <パス>」と通知（自動処理はしません。`.partial.csv` は Excel で開けます） |

PC のフリーズ・電源断ではソフトから負荷を止められません。長時間の無人試験では、SDL 本体側の保護設定の併用も検討してください（SPEC Q-01）。

## 開発

Python 3.12 以上（Windows 11）。

```bat
py -3.12 -m pip install -r requirements.txt
py -3.12 src\main.py          :: GUI を起動
py -3.12 -m pytest            :: 自動テスト
```

### シミュレータ（実機なしで動作確認）

```bat
py -3.12 tools\fake_sdl.py --speed 120
```

127.0.0.1:5025 で SDL のふりをする TCP サーバが起動します。アプリの IP を `127.0.0.1` にして接続してください。
`--speed 120` は時間を 120 倍速で進めます（3000mAh を 1A で放電すると約 1.5 分で終止電圧に達します）。
`--capacity`（mAh）、`--soc`（開始時の充電状態 0〜1）、`--noise`（電圧ノイズ V）も指定できます。

### CLI（GUI なし）

```bat
py -3.12 src\cli.py --host 127.0.0.1 --current 1.0 --cutoff 3.0 --folder out --maker Panasonic --full 4.1V --model NCR18650B
```

### 構成

```
├─ src/
│   ├─ main.py         エントリポイント（GUI）。例外で終了するときも負荷 OFF を送る
│   ├─ gui.py          画面（tkinter + matplotlib）
│   ├─ session.py      放電 1 回分の進行（開始・周期測定・終止判定・再接続・保存）
│   ├─ sdl_client.py   SDL 通信・制御（socket のみ）
│   ├─ recorder.py     積算・一時ファイル・最終 CSV・ファイル名
│   ├─ plotting.py     グラフと PNG
│   ├─ settings.py     設定ファイル
│   ├─ applog.py       ログ（1MB × 3 世代でローテーション）
│   ├─ paths.py        ファイルの置き場所
│   └─ cli.py          CLI
├─ tools/fake_sdl.py   SDL シミュレータ
├─ tests/              自動テスト（pytest）
├─ build.bat           exe を作るスクリプト
└─ build_exe.py        PyInstaller の呼び出し（build.bat から使う）
```

### 使っている SCPI コマンド

| 目的 | コマンド | 確認状況 |
|---|---|---|
| 機器確認 | `*IDN?` | 実機確認済み |
| 測定 | `MEAS:VOLT?` / `MEAS:CURR?` / `MEAS:POW?` | 実機確認済み |
| CC モード | `:SOUR:FUNC CURR` | **実機で要確認**（SPEC Q-02） |
| 電流レンジ | `:SOUR:CURR:IRANG 5` | **実機で要確認** |
| 電流設定 | `:SOUR:CURR:LEV:IMM <A>` | **実機で要確認** |
| 負荷 ON/OFF | `:SOUR:INP:STAT ON` / `OFF` | **実機で要確認** |
| 負荷状態 | `:SOUR:INP:STAT?`（`1`/`0` または `ON`/`OFF`） | **実機で要確認**。開始時と停止時に、負荷が本当に ON/OFF になったかの確認に使います |

コマンドが違っていた場合は `src/sdl_client.py` の `setup_cc` / `set_load` / `load_state` を直してください。

## ビルド（exe の作成）

Windows 11 で `build.bat` をダブルクリックします（Python 3.12 が必要）。
パッケージのインストール → テスト → PyInstaller の順に実行し、`dist\SDL放電ロガー.exe`（単一ファイル）ができます。

GitHub に push すると、GitHub Actions（Windows）でも同じビルドと起動確認（起動時間の測定）が行われ、
exe が Artifacts に保存されます。
